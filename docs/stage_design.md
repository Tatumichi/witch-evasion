# 見習い魔女メルル ステージ設定書（全5階層）

2026-10-22 作成 ／ 土台の設定：[見習い魔女メルル 設定と導入](witch_merulu_setting.md)

## 決定事項

全ステージは「道中約2分＋ボス戦」の構成で、落っこち猫の救助がメルルの唯一の攻め手になります。設定の土台は「見習い魔女メルル 設定と導入」です。

| 項目 | 決定内容 |
| --- | --- |
| 設定の粒度 | 世界観＋ゲーム仕様（障害物の挙動・難易度・セリフまで） |
| 操作 | 上下左右に移動。上昇は自動スクロール |
| 被弾 | 帽子が落ちる。3つ失うと目を回し、ステージ頭からやり直し |
| 収集物 | 共通の「勇気のかけら」＋落っこち猫 |
| 猫 | 高いところが好きで登りすぎて落ちてきた猫。受け止めると毛色で効果が変わる |
| ボス | 毎ステージに1体。一定時間よけ切れば突破、キャンディで時間短縮 |
| 神々 | 名前のない群衆として実況。個性は付けない |
| プレイ時間 | 1ステージ約2〜3分 |
| 結末 | 神々から初めての魔法を授かる |

## 全ステージ共通仕様

メルルは「よける」と「猫を受け止める」しかできません。攻撃はすべて猫の力で、臆病で優しい彼女らしさを仕様で支えます。

### 操作とライフ

- 画面は自動で上へスクロール。メルルは画面内を上下左右に移動できる
- ライフは「帽子」3つ。ぶつかると帽子が1つ飛んでいき「ひゃっ！」「ご、ごめんなさい〜！」のボイス
- 被弾後1.5秒は無敵（メルルが目をつぶって点滅）
- 帽子がなくなると目を回す。神々「もう一度見せよ」でステージ頭に巻き戻る（上昇は止まらない設定と矛盾しない）
- ボス戦で目を回した場合はボス戦の頭から再開

### 勇気のかけら

- 全ステージ共通の小さな光の粒。障害物のすき間や危険地帯のそばに多く置く
- 50個で帽子が1つ戻る（最大3つ）。帽子が満タンならスコアに加算
- 獲得時にメルルが小声で「……がんばれ、わたし」（10個ごとに1回程度）

### 落っこち猫

高いところが大好きで、登りすぎて足を滑らせた猫たち。各ステージの「いちばん高いもの」から落ちてくるため、上へ行くほど「どこに登ってたの！？」という笑いになります。

- 画面上端に「にゃー！」の吹き出しで予告し、1秒後に落ちてくる。受け止めるとほうきの後ろにしがみつき、効果が15秒続く
- 取り逃すと画面下へ落ちていき、メルル「あっ……ああっ！」。救えなかった数はリザルトとエンディングに反映（下記）
- 効果中に別の猫を受け止めると、効果が入れ替わり時間もリセット。前の猫はほうきの穂先で丸くなって同乗を続ける（見た目のみ）
- 各ステージの道中に3匹＋ボス戦中に1匹、計4匹（ステージ5のみボス戦で2匹）。全体21匹

| 毛色 | 効果 | 内容 |
| --- | --- | --- |
| 茶トラ | キャンディ | 猫が前方へキャンディを自動連射。小さな障害物を壊す。壊すたびメルルが「ごめんね」 |
| 白猫 | バリア | ほうきごとふわふわの毛の殻で包む。効果中は被弾しない |

大きな障害物（雷、彗星、光の柱など）はキャンディでは壊れないため、後半ほど白猫の価値が上がります。

### ボス戦ルール

- 画面上部に「満足ゲージ」。時間経過で自然にたまり、満タンでボスが満足して去る（倒さない。よけ切るだけでクリアできる）
- キャンディを当てるとゲージが早くたまる。「生き物を傷つけず、おやつをあげて満足してもらう」という理屈
- ボス戦の途中、1匹だけ猫が落ちてくる（茶トラか白猫はステージごとに指定）

### 難易度曲線

| ステージ | スクロール速度 | 障害物の密度 | 新要素 | ボス満足まで（最短～最長） |
| --- | --- | --- | --- | --- |
| 1 村の空 | 1.0倍 | 低 | 移動と回避・茶トラ | 25〜50秒 |
| 2 丘と森の上空 | 1.1倍 | 低〜中 | 横風・白猫 | 30〜60秒 |
| 3 雲の層 | 1.2倍 | 中 | 予告攻撃（光ってから落雷） | 35〜70秒 |
| 4 星の海 | 1.3倍 | 中〜高 | 高速の斜め弾・分裂 | 40〜80秒 |
| 5 神域の門 | 1.4倍 | 高 | 画面全体攻撃・3段階ボス | 50〜90秒 |

## STAGE 1　村の空

操作を覚えるチュートリアル。障害物はすべてゆっくりで、神々はまだ気づいていません。ボスも神々の仕業ではなく、村の「ちょっとした事故」です。

**風景**：朝焼けのオレンジ色。赤い屋根と煙突が並ぶ村から始まり、教会の塔を越えたあたりで村全体が見下ろせる。終盤で屋根が画面下に消え、空だけになる。

### 障害物

| 障害物 | 動き | 攻略のポイント |
| --- | --- | --- |
| 飛んできた洗濯物 | シーツや靴下がゆらゆら横に流れる。シーツは大きい | 最初の障害物。遅いので「動けばよけられる」を学ぶ |
| 鳩の群れ | 5〜7羽が一列で画面を横切る。列のどこかに1羽分のすき間 | すき間を探して通る |
| 風見鶏 | 屋根から外れて、くるくる回りながら下へ落ちてくる | 上から来る障害物を知る |
| 煙突の煙 | 下から立ち昇る灰色の帯。当たり判定なし、中にいるとメルルが咳き込んで少し遅くなる | 「当たっても痛くないもの」もあると知る |

### 落っこち猫

| 出現 | 毛色 | どこから落ちたか |
| --- | --- | --- |
| 道中序盤 | 茶トラ | パン屋の煙突のてっぺん。あたたかくて居眠りしていた |
| 道中中盤 | 茶トラ | 物干し竿。洗濯物と一緒に飛んできた |
| 道中終盤 | 茶トラ | 教会の塔の鐘。鐘が鳴って驚いた |
| ボス戦 | 茶トラ | 大風見鶏のとさか |

最初の猫は必ずメルルの真上に落ちてくる配置にし、動かなくても受け止められるようにします。

### ボス：ぐるぐる大風見鶏

村いちばんの物知りと言われる大風見鶏。とさかに猫がぶら下がったせいで回転が止まらなくなり、風をまき散らしています。

1. 左右にゆっくり揺れながら、矢印型の風向き板を3方向に飛ばす
2. ぐるっと一回転して突風。メルルが画面端へ押し流される（当たり判定なし）
3. 突風に乗って洗濯物が大量に飛んでくる

満足すると：猫がいなくなって回転が落ち着き、風見鶏が「コケッ」と来たべき方角を向き直して村へ戻っていく。

### セリフ

- 開始時　メルル「ひゃっ……洗濯物が、飛んでくる〜！！」
- 最初の猫　メルル「ね、猫ちゃん！？　だ、だいじょうぶ……つかまって！」
- キャンディ初発動　メルル「えっ、それグランマのおやつ……どこから出したの！？」
- 教会の塔を越えたとき　メルル「塔より、高い……いやいやいや、下見ない。下見ない。」
- ボス登場　メルル「風見鶏さん、うしろに猫ちゃんが！　ちょっとだけじっとしてて〜！」
- クリア後（画面外、はるか上から）　神々「……ん？　今、下で何か光らなかったか？」

## STAGE 2　丘と森の上空

「横風」を学ぶステージ。風が吹くと障害物もメルルも同じ方向へ流されます。神々が初めてメルルに気づきます。

**風景**：青空。眼下に緑の丘と風車小屋、その奥に深い森。終盤は森いちばんの大木のてっぺんをかすめ、わた雲が近づいてくる。

### 障害物

| 障害物 | 動き | 攻略のポイント |
| --- | --- | --- |
| たんぽぽの綿毛の嵐 | 小粒の綿毛が大量に横風で流れる。1粒ずつは当たり判定が小さい | 細かいすき間をぬう。キャンディでまとめて吹き飛ばせる |
| 風船 | 下からゆっくり昇ってくる。ぶつかると割れてメルルが驚き、少し弾かれる | 「下から来るもの」を初めて意識させる |
| 渡り鳥 | V字の隊列で斜めに横切る。隊列の内側は安全地帯 | V字の「くぼみ」に入り込む |
| 風車の羽根 | 画面端の風車小屋から、回転する羽根が張り出す | 回転のタイミングを見て通る |
| 横風（環境） | 画面端の草がなびく予告の後、3秒間左右どちらかへ流される | 風上へ向かって移動し続ける |

### 落っこち猫

| 出現 | 毛色 | どこから落ちたか |
| --- | --- | --- |
| 道中序盤 | 白猫 | 風車の羽根。ちょうどてっぺんに来たところでつるっと |
| 道中中盤 | 茶トラ | 迷子の風船につかまっていた |
| 道中終盤 | 白猫 | 森いちばんの大木のてっぺん |
| ボス戦 | 茶トラ | はぐれ大風車の軸の上 |

白猫の初登場は綿毛の嵐の直前に置き、「バリアがあれば突っ切れる」を体験させます。

### ボス：はぐれ大風車

丘の上の大風車が、強い上昇気流で小屋ごと浮かび上がってしまったもの。回るたびに羽根で風を起こしています。

1. 4枚の羽根がゆっくり回転。羽根の間を押し流されないように通る
2. 回転が速まり、風車の向きに合わせて強い横風が吹く
3. 粉ひき小屋から小麦粉の袋が放り出され、破れて白い粉が視界をふさぐ（粉は当たり判定なし）

満足すると：風がやんで羽根が止まり、風車は帆をたたんでふんわりと丘へ帰っていく。

### セリフ

- 開始時　メルル「村が、もうあんなに小さい……グランマ、ぜったい怒ってるよね……」
- 横風初回　メルル「か、風さん、押さないで〜！」
- 綿毛の嵐　メルル「ふわふわでかわいいけど、いまはこわい〜！」
- 風船を割ったとき　メルル「ひゃっ！　ご、ごめんなさい……誰かの風船だったのに……」
- 神々の実況（中盤、画面上端に小さく吹き出し）　神々「おや、何か昇ってくるぞ。」「猫を拾いながらじゃ。」
- ボス登場　メルル「風車さんが……飛んでる！？　どういうこと〜！？」
- クリア後　神々「風車をよけきったぞ。」「……もう少し、派手にしてみるか。」

## STAGE 3　雲の層

「予告を見てよける」を学ぶステージ。ここから神々がこっそり障害物を足し始め、自然の空が少しずつ不自然になります。

**風景**：入り口は灰色の雨雲で薄暗い。中盤で雲を抜けると、一面の白い雲海と大きな虹が広がる。終盤は夕焼け色に変わり始める。

### 障害物

| 障害物 | 動き | 攻略のポイント |
| --- | --- | --- |
| 雷雲 | 雲がピカッと光って1秒後、真下へ縦一直線に落雷。キャンディでは壊せない | 光った雲の真下から逃げる |
| 大粒の雨 | 上から斜めに降る大きなしずく。当たると帽子が落ちる | 斜めの流れに沿って動く |
| 空クジラの潮吹き | 雲海の下から水柱が上へ吹き上がる。直前に雲がモコモコ盛り上がる | 「下からの予告攻撃」。雲の盛り上がりを見る |
| 霧のかたまり | 当たり判定なし。通ると数秒間、画面が白くもやがかかる | 霧の奥に雷が隠れていることがある |
| 虹（ボーナス） | 画面を斜めに横切る虹。上をなぞると勇気のかけらが連続で手に入る | 難しい区間のごほうび |

### 落っこち猫

| 出現 | 毛色 | どこから落ちたか |
| --- | --- | --- |
| 道中序盤 | 白猫 | 雲を「大きな布団」だと思って登ったら、すり抜けた |
| 道中中盤 | 茶トラ | 虹のいちばん高いところ。すべり台のように滑ってくる |
| 道中終盤 | 白猫 | 雷雲の上。毛が静電気でぼわぼわ |
| ボス戦 | 茶トラ | 空クジラの背中。潮吹きで打ち上げられてくる |

雷はキャンディで壊せないため、雷雲が多い前半は白猫を多めに置きます。

### ボス：空クジラのボヨン

雲海を泳ぐ、家より大きな空クジラ。悪気はなく、珍しい小さな魔女と遊びたがっています。後半は神々がこっそり雷を足します。

1. 画面を左右にゆったり横切り、通った後に潮吹きの水柱を3本立てる
2. 尾びれで雲海を叩き、雲の波が画面下からせり上がる（上へ逃げる）
3. 神々の「ちょい足し」。クジラの動きに合わせて雷雲が湧き、落雷が加わる

満足すると：キャンディがすっかり気に入ったボヨンが、大きな潮吹きで虹をかけてから雲海へ潜っていく。

### セリフ

- 開始時　メルル「雲の中って……ふわふわじゃなくて、つめたい〜……」
- 初めての雷　メルル「ひゃっ！！　い、いま光ったよね！？　光ったら逃げる、光ったら逃げる……」
- 雲を抜けて虹を見たとき　メルル「……きれい。……って、見とれてる場合じゃない〜！」
- 神々の実況　神々「雷をひとつ足してみよ。」「ほう、よけた。」「今のは偶然じゃ。もうひとつ。」
- ボス登場　メルル「く、くじらさん！？　お、おいしくないですよ、わたし〜！」
- ボヨンにキャンディが当たったとき　ボヨン「ボォーン♪」　メルル「……よろこんでる？」
- クリア後　神々「客席を用意せよ。」「久しぶりに面白くなってきた。」

## STAGE 4　星の海

速い斜め弾と分裂する障害物で、反射神経を試すステージ。神々の客席ができ、障害物ははっきり「見せ物」になります。

**風景**：空が紺から深い紺色へ。天の川が画面を斜めに流れ、両端の雲の上に神々の客席（光るシルエット）が並ぶ。メルルがうまくよけると客席が波打つように光る。

### 障害物

| --- | --- | --- |
| 流れ星 | 画面端に光の線で軌道を予告し、斜めに高速で飛ぶ。小さいのでキャンディで壊せる | 予告線から外れる |
| 彗星 | 大型でゆっくりだが、長い尾にも当たり判定。壊せない | 尾が通り過ぎるまで待つ |
| シャボン玉の惑星 | ゆらゆら漂う大きな玉。キャンディが当たると割れて小さな玉に分裂する | 壊すとかえって危ない。射線を意識する |
| 星座の線 | ばらばらの星が順に点灯し、全部つながると光の線に当たり判定が生まれる | つながる前に線の外へ出る |
| 神々の歓声（環境） | うまくよけた直後、客席から紙テープが飛んでくる。当たり判定なし | 演出と障害物を見分ける |

### ボス：おおねこ座

神々が「猫を拾う小娘じゃ、猫でもてなそう」と星をつないで作った、巨大な猫の星座。本物の猫と同じく、動くものにじゃれつきたがります。

1. 前足でじゃれつく。画面を大きくひっかく光の線が3本、点滅予告の後に現れる
2. 星の毛玉を転がす。画面端で跳ね返る大きな玉
3. 伸びをして体をつなぐ星がばらけ、流れ星の雨になって降り注ぐ

満足すると：ゴロゴロと喜び、丸くなってその場で眠ってしまう。以降、夜空に「丸まった猫の星座」が残る。

### セリフ

- 開始時　メルル「……夜？　さっき夕方だったのに……ついに、空の外まで来ちゃった……？」
- 客席に気づく　メルル「だ、誰か見てる！？　いやだ〜、目立ちたくないよ〜！」
- シャボン玉を割ったとき　メルル「ごめんなさいって……増えた〜！？」
- 神々の実況　神々「彗星を通せ。」「またよけたぞ。」「あの小娘、よけるたびに謝っとる。」「なぜじゃ。」
- ボス登場　メルル「お、おっきい猫ちゃん……！？　その子も落ちたら、受け止められないよ〜！」
- クリア後　神々「ここまで来た人間は何百年ぶりか。」「……よかろう。最後は、わしら自ら試そう。」

## STAGE 5　神域の門

これまでの要素をすべて使う最終ステージ。神々が自ら「最後の試し」をしかけ、ボスは3段階です。

**風景**：星空が金色の光に変わり、黄金の雲と白い石の柱が並ぶ。終盤に巨大な黄金の門が現れ、その向こうが「世界でいちばん高い場所」。

### 障害物

| 障害物 | 動き | 攻略のポイント |
| --- | --- | --- |
| 天使のラッパの衝撃波 | 天使が吹くと、同心円の光の輪が広がる。輪の一か所だけ切れ目がある | 切れ目を探してくぐる |
| 降り注ぐ光の柱 | 地面に丸い光の印が出て、1秒後に縦の光の柱が落ちる。複数同時。壊せない | 印のない場所へ移る |
| 金の紙吹雪 | 大量に舞う。ほとんどは演出だが、大きな金の紙だけ当たり判定あり | 大きさと輝きで見分ける |
| 聖歌隊の音符 | 天使の歌に合わせて音符が波形に並んで流れる。キャンディで壊せる | 波のリズムに合わせて上下する |
| 過去ステージの「特別出演」 | 洗濯物、綿毛、雷、流れ星が金色になって再登場。速度は1.4倍 | 学んだことのおさらい |

### ボス：神々の最後の試し

姿の見えない神々が、大きな光の手だけを雲から伸ばして演出します。満足ゲージは3段階で、段階ごとに攻撃が変わります。

1. **光の手**：左右から大きな手が現れ、メルルをつまもうとする。影で予告
2. **天使の合奏**：ラッパの衝撃波と光の柱が同時に来る
3. **閉じる門**：黄金の門が左右からゆっくり閉じ、すき間が狭まっていく。そこへ金の紙吹雪が降る。閉じきる前に満足させれば門が開く

満足すると：門が大きく開き、ほうきが門の向こうの雲の上でようやく止まる。そのままエンディングへ。

### セリフ

- 開始時　メルル「まぶしい……ここが、いちばん高いところ……？　もうちょっとだけ、がんばれ……」
- 過去の障害物が金色で出たとき　メルル「せんたくもの……きんいろです〜！？」
- 神々の実況　神々「あれを出せ。」「これも出せ。」「全部出せ。」
- ボス第1段階　神々「小さき魔女よ。最後の試しじゃ。」　メルル「か、神さま……！？　ご、ごめんなさい、勝手に来てごめんなさい〜！」
- 第3段階　メルル「閉まっちゃう……ここまで来たのに……！　こわいけど……こわいけど、行く！」
- 突破時　神々「……通したぞ。」「通したのじゃない。通られたのじゃ。」

## エンディング：初めての魔法

神々がメルルに授けるのは、落ちるものをそっと受け止める「ふわりの魔法」です。猫を救い続けた行いそのものが魔法になり、しかも「安全に下りるための魔法」として帰り道にもつながります。

### 流れ

1. 黄金の庭でほうきが止まる。メルルは腰を抜かし、しがみついたまま動けない
2. 神々が取り囲む。「全部よけた人間は初めてじゃ」「しかも、よけるたびに謝っとった」
3. 救った猫たちがほうきから降り、メルルのまわりに丸くなる（数は実際に救った匹数）
4. 神々「小さき魔女よ。おまえは一度も、自分のために手を伸ばさなかった」→ メルルの手のひらに、羽根のような光が置かれる
5. 帰り道。メルルが「ふわり」と唱えると、猫たちごとゆっくり下へ降りていく。通ってきた空（星・雲・丘・村）が逆順に流れ、ボヨンや風見鶏が手を振る
6. 裏庭に着地。膝の高さから、ぴょんと地面へ。メルル「……地面。……地面だぁ〜……！」

### 救った猫の数による差分

| 救った猫 | 差分 |
| --- | --- |
| 21匹（全員） | 猫たちがそのままメルルの家に住みつく。最後の一枚絵が「猫だらけの裏庭」になる |
| 11〜20匹 | 標準エンド。猫たちは村へ散っていくが、屋根の上からメルルを見守る |
| 0〜10匹 | 神々「救いきれなんだ猫も、わしらが受け止めておいた」。取り逃した猫も安全だと示し、ほのぼのさを保つ |

どの差分でも、取り逃した猫がけがをした描写は入れません。「助けないと大変なことに」という緊張はプレイ中の「ああっ！」で見せ、結末で安心させる構成です。
