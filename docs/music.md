# 音楽（BGM）

シリーズを通してピアノ独奏で統一する。明るいが騒がしくなく、どこかせつない響きを基調にする。

## 曲一覧

| 曲 | 使う場面 | 調・拍子・テンポ | ループ |
| --- | --- | --- | --- |
| 村の空 | STAGE 1 タイトル〜道中 | 変ホ長調・4/4・80 | 12.000 秒 → 108.000 秒（イントロ 4 小節は初回のみ） |
| 迷子の風見鶏 | STAGE 1 ボス戦 | ハ短調・3/4・172 | 4.186 秒 → 46.047 秒（回転モチーフだけのイントロは初回のみ） |

### 村の空

朝焼けの村の上を、ゆっくり押し上げられていくイメージ。

- 素直な進行（I–V–vi）で明るさを出し、短和音（vi・iii）を多めに入れてせつなさを混ぜる
- B メロ後半の **A♭m6**（同主短調からの借用）で、メロディが一瞬半音下がる。地面が遠ざかる心細さ
- 構成: イントロ 4 → A 8 → A' 8 → B 16 → A へ
- 冒頭の B♭–G–F の下降はメルルのテーマとして、以降の曲でも引用する

### 迷子の風見鶏

くるくる回り続けて向きがわからなくなった風見鶏が、上へ昇るメルルの影を追いかけてくる。

- 3 拍子のワルツの上に、4 音の回転モチーフ（G–A♭–G–F#）を 8 分音符で重ねる。4 音のまとまりは 2 小節半で一周するので、アクセントが小節ごとにずれ、「どこが頭かわからない」
- A: ハ短調。ベースが C–B–B♭–A♭ と半音ずつ下がり、回りながら沈んでいく
- B: 変ホ長調。**村の空の冒頭（B♭–G–F）をワルツで引用**し、メルルを見つけて惹かれる場面にする。A♭m もここで再登場
- C: 回転モチーフをオクターブで強く弾く追いかけっこ。ここから A に戻る

## ファイル

| 場所 | 内容 |
| --- | --- |
| `tools/music/stage1_bgm.py` / `boss1_bgm.py` | 作曲データ（音符）と書き出し。簡易ピアノ合成の処理も `stage1_bgm.py` にある |
| `art/music/*_loop.mid` | MIDI 原本。右手・左手の 2 トラック、`loop_start` / `loop_end` マーカー付き。DAW で本物のピアノ音源に差し替えるときはこれを使う |
| `godot/assets/audio/bgm/*.ogg` | ゲーム用。イントロ＋ループ本体で終わり、ループ末尾の余韻はループ頭に折り返してある |
| `godot/scripts/stage/bgm.gd` | 再生制御。`stage1.tscn` の `BGM` ノード |

書き出し（リポジトリのルートで。`pip install mido numpy scipy`、ffmpeg が必要）:

```bash
python tools/music/stage1_bgm.py
python tools/music/boss1_bgm.py
```

DAW で作り直した音源に差し替える場合も、同じ構成（イントロ＋ループ本体で終わる・余韻はループ頭へ折り返す）で OGG を書き出し、ループ位置が変わったら `bgm.gd` の `TRACKS` と各 `.ogg.import` の `loop_offset` を合わせる。

## 再生のしかた（bgm.gd）

`stage1.gd` には手を入れず、`BGM` ノードが親の `state` の変化を見て切り替える。

| 状態 | BGM |
| --- | --- |
| TITLE / INTRO / ROAD | 村の空。タイトルから鳴らし、開始しても頭に戻さない |
| BOSS_INTRO / BOSS | 迷子の風見鶏。回転モチーフのイントロがボス登場演出に重なる |
| CLEAR | ボス曲を 2.5 秒でフェードアウト |
| FAINT | 音量を下げて待つ。やり直しで、道中なら村の空、ボス戦なら迷子の風見鶏を頭から |

検証: `godot --headless --path godot --fixed-fps 60 --script res://tests/verify_bgm.gd`
