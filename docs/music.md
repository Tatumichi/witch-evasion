# 音楽（BGM）

シリーズを通してピアノ独奏で統一する。明るいが騒がしくなく、どこかせつない響きを基調にする。

### 村の空

朝焼けの村の上を、ゆっくり押し上げられていくイメージ。

- 素直な進行（I–V–vi）で明るさを出し、短和音（vi・iii）を多めに入れてせつなさを混ぜる
- B メロ後半の **A♭m6**（同主短調からの借用）で、メロディが一瞬半音下がる。地面が遠ざかる心細さ
- 構成: イントロ 4 → A 8 → A' 8 → B 16 → A へ
- 冒頭の B♭–G–F の下降はメルルのテーマとして、以降の曲でも引用する

### 迷子の風見鶏

くるくる回り続けて向きがわからなくなった風見鶏が、上へ昇るメルルの影を追いかけてくる。

- 3 拍子のワルツの上に、4 音の回転モチーフ（G–A♭–G–F#）を 8 分音符で重ねる。4 音のまとまりは 2 小節半で一周するので、アクセントが小節ごとにずれ、「どこが頭かわからない」
- A: ハ短調。ベースが C–B–B♭–A♭ と半音ずつ下がり、回りながら沈んでいく
- B: 変ホ長調。**村の空の冒頭（B♭–G–F）をワルツで引用**し、メルルを見つけて惹かれる場面にする。A♭m もここで再登場
- C: 回転モチーフをオクターブで強く弾く追いかけっこ。ここから A に戻る

### 丘と森の上空

青空と横風。眼下の丘と風車、その奥の森。

- テンポは村の空の 1 割増し（スクロール 1.1 倍に合わせる）
- 左手は 3 連符で上がって下がる**揺れる伴奏**（12/8 の感じ）。村の空のまっすぐな 8 分と変える
- 構成: イントロ 4 → A 8 → A' 8 → B 8 → C 8 → つなぎ 4 → A へ（ループ本体 36 小節・約 98 秒）
- B は横風: ハ短調に陰り、伴奏の揺れが 1 音高くまで届き、2 小節ごとに押し寄せて引く強弱の波を付ける
- C は大木とわた雲: **メルルのテーマ（B♭–G–F）**をオクターブで歌い、最後に A♭m6（村の空と同じ借用和音）
- つなぎの最後の小節で 3 連符を駆け上がり、A の頭へ戻る

### はぐれ大風車

丘の風車が小屋ごと浮かび上がってしまった。4 枚の羽根が大きくゆっくり回る。

- 左手は **4 拍で一周する重い低音**（根音–5 度–オクターブ–5 度）。1 拍目は羽根が真下を通るように、さらに 1 オクターブ下を足す。2・4 拍目に中音域の和音を軽く（風切り）
- A（ゆっくり回る）: 二分音符の大きな旋律をオクターブで
- B（突風）: 低音が 8 分に詰まり、右手は 16 分の走句が和音を 2 オクターブ駆け上がって駆け下りる
- C（小麦粉が舞う／帰りたい丘）: 変ホ長調に明るみ、メルルのテーマと A♭m を引用。ここから A へ
- 迷子の風見鶏（ハ短調・3/4・ワルツ）と同じ調で、拍子（4/4）と重さを対にする

## ファイル

| 場所 | 内容 |
| --- | --- |
| `tools/music/stage1_bgm.py` / `boss1_bgm.py` / `stage2_bgm.py` / `boss2_bgm.py` | 作曲データ（音符）と書き出し。簡易ピアノ合成とループ書き出しの処理は `stage1_bgm.py` にあり、STAGE 2 以降は `common.py`（音名・旋律の書き方・MIDI 書き出し）と合わせて使う |
| `art/music/*_loop.mid` | MIDI 原本。右手・左手の 2 トラック、`loop_start` / `loop_end` マーカー付き。DAW で本物のピアノ音源に差し替えるときはこれを使う |
| `godot/assets/audio/bgm/*.ogg` | ゲーム用。イントロ＋ループ本体で終わり、ループ末尾の余韻はループ頭に折り返してある |
| `godot/scripts/stage/bgm.gd` | 再生制御。`stage1.tscn` の `BGM` ノード |

書き出し（リポジトリのルートで。`pip install mido numpy scipy`、ffmpeg が必要）:

```bash
python tools/music/stage1_bgm.py
python tools/music/boss1_bgm.py
python tools/music/stage2_bgm.py
python tools/music/boss2_bgm.py
# --preview を付けると、ループを 2 周して終わる試聴用 WAV もカレントに書き出す（stage2 / boss2）
```

DAW で作り直した音源に差し替える場合も、同じ構成（イントロ＋ループ本体で終わる・余韻はループ頭へ折り返す）で OGG を書き出し、ループ位置が変わったら `bgm.gd` の `TRACKS` と各 `.ogg.import` の `loop_offset` を合わせる。

## 再生のしかた（bgm.gd）

ステージのスクリプトには手を入れず、`BGM` ノードが親の `state` の変化を見て切り替える。
どの曲を鳴らすかはステージに聞く: ステージが `bgm_track(role)`（role は `"road"` / `"boss"`）を持っていれば、その名前（`bgm.gd` の `TRACKS` のキー）の曲を鳴らす。持っていなければ STAGE 1 の曲。
STAGE 2 は「丘と森の上空」「はぐれ大風車」を返す（`stage2.gd`。ファイルが無ければ STAGE 1 の曲に戻る）。曲を差し替えてループ位置が変わったら `TRACKS` の `loop_offset` を直す。

| 状態 | BGM |
| --- | --- |
| TITLE / INTRO / ROAD | 村の空。タイトルから鳴らし、開始しても頭に戻さない |
| BOSS_INTRO / BOSS | 迷子の風見鶏。回転モチーフのイントロがボス登場演出に重なる |
| CLEAR | ボス曲を 2.5 秒でフェードアウト |
| FAINT | 音量を下げて待つ。やり直しで、道中なら村の空、ボス戦なら迷子の風見鶏を頭から |

検証: `godot --headless --path godot --fixed-fps 60 --script res://tests/verify_bgm.gd`

ヘッドレス実行（検証・CI）では実際の音は出さない。Godot は再生中のまま終了すると「resources still in use」を出すため。曲の選択と音量の変化はそのまま動き、`current_track()` などで確かめられる。
