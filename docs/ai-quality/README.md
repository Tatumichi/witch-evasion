# ComfyUI イラスト品質向上プロジェクト

生成イラストを「AIっぽい」で終わらせず、ゲームに使える品質まで持っていくための調査・改善プロジェクト。

## 前提環境

| 項目 | 内容 |
|---|---|
| 生成基盤 | ComfyUI 0.42.0（`C:\AI\ComfyUI`） |
| モデル | Animagine XL 4.0（SDXL / アニメ調） |
| 実行環境 | RTX 3060 12GB / CUDA |
| 生成クライアント | `tools/comfy.py`（ワークフローは PNG 横の `.json` に保存） |
| 出力先 | `art/`（検討用）→ `godot/assets/`（採用分） |

## 進め方

品質を「気合とプロンプトの工夫」で上げるのではなく、**破綻を定義 → 検出 → 修正 → 再評価**のループとして扱う。

1. **理解**: なぜAIっぽく見えるのかを原理から把握する（← 今ここ）
2. **計測**: 破綻をチェックリスト化し、出力を定量的に見る
3. **介入**: 構造制御・局所修正・多段生成・後処理で層ごとに潰す
4. **評価**: 自動検出と人間評価を併用し、改善を確認する

## 現状の結論（要約）

- 「AIっぽさ」の正体は画力不足ではなく、**因果の欠落**・**大域整合性の欠落**・**平均化と高周波の欠落**の3つ。
- 人間が一瞬で見抜くのは、破綻の発生場所と視覚の優先順位（輪郭・顔・光の整合性）が一致しているため。
- 品質は平均点ではなく**最弱の破綻（最小値）**で決まる。1つの破綻が99点の絵を0点にする。
